# SPA Example — Vue / TypeScript

Пример моего frontend-кода из внутреннего SPA на Vue 3 и TypeScript.

В репозитории представлен модуль работы с кодами маркировки:
табличный интерфейс, фильтрация, сортировка, пагинация,
редактирование данных и групповые действия.

## Формат примера

Репозиторий предназначен для ознакомления с исходниками,
а не для самостоятельного запуска.

Часть модулей исходного приложения и внутренние зависимости
недоступны в этом репозитории. В частности, используются закрытые
пакеты UI-компонентов, иконок и утилит.

## Стек

Vue 3, Composition API, TypeScript, Pinia, Vue Router,
Vite, SCSS, Keycloak.
